Welcome to Cell Data Viewer

This page centers around an interactive map which uses map data from the external servers of the OpenStreetMap Foundation (UK) and ESRI Inc. (US). Your consent is therefore required before your browser can send requests to these external services. These requests transmit potentially identifying information to these companies. This includes the location of the requested map sections, your public IP address, information about your operating system, and information about your browser. Please see the privacy policy for further information. Your consent is valid for the next 30 days or until there is a significant change regarding map data, whichever comes first. Both the consent itself and the time of consent are stored on your device. You can find more information about the data stored on your device in the privacy policy. After you have given consent the map will load and a prompt to share your location will appear. This location information will only be used to initially center the map on your location from your next visit.

How can I save the points I collect to a CSV file?

  1. Open the hamburger menu in the top left of the app (three horizontal lines).
  2. Tap on the "Settings" option to navigate to the settings of the app.
  3. Enable the output to CSV file option, which can be found in the Main Settings section.
  4. Use the record function of the app to collect data points. On each day you record data points, a new CSV file will be created with the collected data points. The CSV file will be updated with new data points as you collect them.

The "Signal Mapping" function needs the be configured in the CoverageMap Android app. This can either be done during the first time setup of the application or later from the "More" menu. You can choose to map signal data always while the app is in the background or only while the app is in the foreground.

  1. Tap on the "More" option on the right of the bottom navigation.
  2. Tap on the "Signal Mapping" option.
  3. Here you can configure the mapping of signal data points to your liking. The most importantly you need to change the "Contribute Data" option from "Never" to either "Always" or "While using the app". If permissions are missing you will be asked to grant them.

Use the record function of the app to collect data points. Each time you start a new recording session, a new CSV file will be created with the collected data points. The CSV file will be updated with new data points as you collect them.

Use the record function of the app to collect data points.

After ending the recording, you can export the collected data points to a CSV file following these steps:

  1. Tap on the three-dots menu in the top right corner of the app.
  2. In the three-dots menu tap on the "Export" option.
  3. In the preferences menu tick the "CSV" option checkbox.
  4. Tap on the "Export" button.
  5. At this point the CSV file is exported and can be opened in the web tool through the file picker of your Android device. But in the following pop-up you can select to just keep the CSV file on the device or to directly share it to another app or device. Depending on your selection the "Keep" button changes to a "Share" button.

Where do I find the CSV files?

The CSV files can be found on your Android device in the following folder: Internal Storage -> Android -> data -> cellmapper.net.cellmapper -> files

Please note that if you use the web tool directly on an Android device the CSV files can't be opened directly from this folder via the file picker. This limitation is due to the security aspect that apps shouldn't be able to access storage regions of other apps. The only exception is the build in Android Files application (com.google.android.documentsui) when it's opened from the launcher (home screen & app menu) or via an activity launcher. This should not be confused with the Files by Google application or any other manufacturer provided files application. With this Android Files application, it's possible to copy the CSV files from the above mentioned folder to another folder like Downloads, Documents or any other folder outside of the Android folder. Then the CSV files can be opened from the web tool via the file picker. If your Android device doesn't have a shortcut to the Android Files application by default it is possible to add one either via the Files shortcut app from Marc apps & software / Marc-JB (easy option) or via an activity launcher app such as Activity Launcher by Adam M. Szalkowski and add a shortcut to the com.android.documentsui.files.FilesActivity activity to the home screen (advanced option).

If you want to use the web tool on a computer you can connect your Android device via a USB cable to access the CSV files. Alternatively, you can share the CSV files to a computer from the Android Files application described above.

The CSV file with all collected data can be downloaded from the CoverageMap website.

  1. Open the menu with the hamburger button in the top left.
  2. From the menu choose the "View My Tests" option. Here make sure that you are logged in with the Apple or Google account that you used to log in on your Android device.
  3. Next click on the "Exports Results" option in the top right.
  4. Finally, click on the "Signal Data" option to download the CSV file with all of the colleted signal points.

An additional path for G-MoN Pro is that you can find the CSV files in the app by following these steps:

  1. Open the three dot menu in the top right corner of the app.
  2. In the three dots menu select the "File Manager" option.
  3. In the file manager you can see, select and share the CSV files to other apps and devices. For example you can share them to a network/cloud storage location.

You might be able to open the CSV files from a network/cloud storage location via the file picker on your Android device depending on the app you use for the network/cloud storage location.

If you want to use the web tool on a computer you can connect your Android device via a USB cable to access the CSV files. Alternatively, you can share the CSV files to a computer from the G-MoN Pro application or the Android Files application described above.

When you use the Export function for the first time, you need to create and/or select a folder in which the app will store the export files every time you use the Export function.

If you have trouble finding that folder again, follow these steps to rediscover the folder you have selected for the export files:

  1. Open the three-dots menu in the top right corner of the app.
  2. In the three-dots menu select the "Preferences" option.
  3. In the preferences menu tap on the "General" option.
  4. Under general tap on the "Change storage location" option.
  5. In the pop-up select the "Proceed" option.
  6. You can now see the selected folder and the path to that folder in the folder picker.

To provide the interactive map function, map data from OpenStreetMap and ESRI is loaded via their external tile servers. These services are required for displaying the map and enable the geographic representation of the collected data points.

OpenStreetMap is operated by the OpenStreetMap Foundation, St John’s Innovation Centre, Cowley Road, Cambridge, CB4 0WS, United Kingdom. Further information on data protection can be found here: OpenStreetMap Privacy Policy.

ArcGIS is offered by ESRI Inc., 380 New York Street, Redlands, CA 92373, USA. Further information on data protection can be found here: ESRI Privacy Policy.

When loading map data, your browser will send requests to these third-party servers. This process collects technical information such as your IP address, operating system, operating system version, browser, and browser version, and transmits the requested map area to the respective provider.
